# KAKASHI PLAYER (Android APK Project)

هذا المشروع جاهز لتوليد ملف تثبيت الأندرويد `KAKASHI-PLAYER.apk` بالاسم الرسمي **KAKASHI PLAYER** وبواجهة Netflix الداكنة.

## أسهل طريقتين للحصول على ملف APK جاهز للتثبيت:

### الطريقة الأولى: عبر GitHub مجاناً وبدون تثبيت أي برامج على جهازك (سحابياً)
1. أنشئ مستودعاً (Repository) جديداً على موقع GitHub.
2. ارفع جميع ملفات هذا المجلد إليه.
3. اذهب إلى تبويب **Actions** في المستودع واضغط على **Build KAKASHI PLAYER APK** ثم **Run workflow**.
4. بعد دقيقة واحدة ستجد ملف `KAKASHI-PLAYER-APK` جاهزاً للتحميل وتثبيته مباشرة على هاتفك أو شاشتك الذكية (Android TV).

### الطريقة الثانية: عبر Android Studio
1. افتح مجلد `KAKASHI_PLAYER_Android_Project` داخل برنامج Android Studio.
2. من القائمة العلوية اختر: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
3. ستجد الملف الناتج في المسار: `app/build/outputs/apk/debug/app-debug.apk`.
